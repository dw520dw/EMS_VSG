Unified Modbus config: config/modbus/
  devices.json           -- 设备连接 + template 名（薄）
  templates/<name>.json  -- 点表（read.fields + sink）
  详见 config/modbus/README.txt

分层（Telegraf 式标准化）：
  read.fields[]  -- 绝对地址读 + 标定（唯一读表键名；无 points 别名）
    fc / address / type / scale / bias / pt_exp / ct_exp
    可选 cluster_stride（多簇：eff = address + (clusterIndex-1)*stride）
    可选 name（仅 C++ hook）；可选 bit（reg_bit）
  sink           -- 写 MySQL
    mode=sequential  -- 按 fields 中 write_mysql 顺序写 base_addr+0,1,2...
    mode=explicit    -- 每点 db_addr（稀疏，如 dido）
  引擎           -- 按 fc+address 自动合并连续读请求（无需 blocks/id）
                    读失败保留上轮 cache，不整轮清零
  英文字段 EN    -- 不在采集侧；见桌面 history_uploader（addr→en）

devices[]  -- ess_meter / grid_meter / pcs_ylk / bamu_* / dido_1 / dido_2
  transport 仅允许 rtu|tcp；建总线的主设备需带 rtu_device 或 tcp_ip（从设备可共用总线省略）
  连接参数以 devices.json 为准；main / Config.h 不再传串口与 IP。
  Loader 按 path+mtime 缓存（devices 与各 template 分别缓存）。

Point types:
  u16 i16
  u32_hi_lo / i32_hi_lo   -- 高字在前（现有设备默认；u32/i32 同义）
  u32_lo_hi / i32_lo_hi   -- 低字在前（新设备扩展）
  bit reg_bit virtual_comm virtual
Value: raw * scale * (pt^pt_exp) * (ct^ct_exp) + bias
